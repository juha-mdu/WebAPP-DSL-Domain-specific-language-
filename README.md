# Food Ordering WebApp Modeling using JJODEL
This project presents a Model-Driven Engineering (MDE) solution developed using JJODEL.

The system models a Food Ordering Web Application including:
- WebApp
- Frontend
- Backend
- API
- Database
- Authentication
- Device Profiles
- Data Binding
- Server Configuration

The project also implements:
- Graphical viewpoints
- Hybrid textual serialisation
- Monolithic textual serialisation
## Features
- Custom metamodel
- Dynamic textual serialisation
- Edge associations and compositions
- Enum handling
- Hybrid and monolithic viewpoints
- Automatic model update propagation
  ## Technologies
- JJODEL
- Model Driven Engineering (MDE)
- JSX View Templates
- OCL Constraints
